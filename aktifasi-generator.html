Cara pakai

  1. Pastikan pembayaran Rp 50.000 sudah diterima.
  2. Klik "Generate Kode Baru" lalu salin kodenya dan berikan ke pembeli.
  3. Tambahkan hash-nya ke array activationHashes di script.js.
  4. Catat kode di file privat di luar folder situs. Jangan ikut sertakan file tersebut saat upload/deploy.
