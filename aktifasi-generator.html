Cara pakai

  1. Pastikan pembayaran Rp 50.000 sudah diterima.
  2. Muat file kunci master, klik "Generate Kode Baru", salin kodenya dan berikan ke pembeli.
  3. Tempel potongan kode dari jendela "Pakai untuk dipasang di script.js" ke dalam codes (map hash → bungkus kunci) di script.js.
  4. Catat kode plaintext di file privat di luar folder situs agar kode bisa keluar daftar. Jangan ikut sertakan file tersebut saat upload/deploy.
  5. Kode habis atau sandi berubah? Ulangi langkah 2–3 di atas.
